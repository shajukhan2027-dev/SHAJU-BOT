# 🔥 SHAJU BOT

A WhatsApp Multi-User Pairing Bot Platform.

**Live Demo:** https://shaju-bot.onrender.com

## Features

- WhatsApp Pairing Code
- Multi-user Pairing Architecture
- Live Connection Status
- Welcome Message
- Anti-Link
- Anti-Spam
- Bad Word Filter
- Warning System - 3 Warnings = Kick
- Group Protection
- Auto Reply
- Admin Control
- Responsive Dashboard

## Requirements

- Node.js 20+
- npm
- GitHub Account
- Render Account
